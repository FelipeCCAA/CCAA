Formatos propios: control de proceso mantequilla, control de peso neto, control de pasteurización, cámara climatizada, certificado de liberación de mantequilla (CCAA.MAN.FORM.*). La receta multinivel ya lo contempla: mantequilla ← crema ← leche fresca.
Codificación de lote (CCAA.Calidad.POE.009.02). El código no es libre: es CCAA + <año><día juliano> + sufijo. Ej.: elaborado el 16-07-2025 → CCAA5197. Sufijo: N = uso nacional · 1 = Egron 1 · 2 = Egron 2 · sin sufijo = crema · A = segunda producción del mismo día (evita duplicidad). → El sistema puede autogenerar y validar el código a partir de fecha + línea + destino, en vez de teclearlo.

La regla que justifica el sistema — el Dossier de Liberación

Un despacho exige un lote liberado. Un lote se libera cuando sus 19 registros están completos, firmados y conformes. Este es el checklist real (CCAA.Calidad.FORM.023), en orden de flujo. Cada registro se convierte en datos capturables; la columna final indica la entidad propuesta.

Comportamiento del sistema. El botón «Autorizar despacho» permanece bloqueado hasta el 100% de los registros completos y conformes contra la especificación vigente a la fecha del lote. Un registro observado bloquea la liberación aunque el resto esté completo. El cierre requiere V°B Fabricación + V°B Calidad. La liberación bajo concesión (producto fuera de especificación aceptado por el mandante o reproceso) exige motivo escrito y autorizador identificado, y queda marcada de forma permanente — no es una puerta trasera, es el registro que la auditoría busca.

Modelo de datos — existente + propuesto

El modelo actual de la app (esquema.js / dominio.js) ya cubre la columna vertebral: recepción → silos → lote → análisis → liberación → despacho, con especificaciones versionadas y recetas multinivel. Lo que el levantamiento agrega son las entidades de control de proceso, inocuidad y saneamiento que hoy viven sólo en planillas y que son exactamente lo que una auditoría FSSC revisa.
